# Инструкция для ИИ-ассистента

Пользователь хочет смотреть статистику своих соцсетей из Livedune в Дашкрафте. Помоги ему запустить дашборд на его данных у него на компьютере.

## Только локально

- Запускай Дашкрафт на компьютере пользователя (`npm run dev`, http://localhost:3000). Не выкладывай его на хостинг, в облако или туннели (ngrok и т. п.) по своей инициативе.
- Если пользователь сам просит открыть дашборд другим по ссылке, объясни риски: без пароля статистику увидит любой, у кого есть ссылка, и каждый заход тратит лимит API. Выкладывай только с паролем (Vercel Password Protection, Cloudflare Access, basic auth) — см. «Если нужно показать дашборд другим» в README.

## Ключ Livedune — секрет

- Ключ кладётся только в `.env.local` в корне проекта. Этот файл в `.gitignore` и не попадает в git.
- Не вставляй ключ в код, README, коммиты, логи, скриншоты и адреса страниц.

## Тариф Livedune

Данные идут через API Livedune, а у тарифов разные лимиты запросов в месяц: Триал — 100 на весь период, Фримиум — 100, Блогер — 2 000, Бизнес — 10 000, Агентство — 100 000 ([вики Livedune](https://wiki.livedune.com/ru/articles/11640100-api/)). Дашкрафт тратит примерно 2–4 запроса на аккаунт за каждый новый период.

- Если у пользователя Триал или Фримиум — предупреди, что лимита хватит на несколько просмотров, и для постоянной работы нужен тариф от «Блогера».
- Если Livedune отвечает 402 или дашборд пишет, что запросы закончились, — дело в лимите, а не в коде.
- Если у пользователя ещё нет Livedune, дай ссылку на регистрацию: https://pro.livedune.com?from=72df001bad

## Запуск

```bash
npm install
cp .env.example .env.local   # впиши LIVEDUNE_TOKEN
npm run dev                   # http://localhost:3000 — только на этом компьютере
```

Если в шапке есть плашка «Демо» — ключ не подхватился: проверь `.env.local` и перезапусти `npm run dev`.

## Проверь, что видны все аккаунты

1. Список аккаунтов из Livedune:

   ```bash
   npm run accounts
   ```

   Команда печатает проект, соцсеть, тип и название каждого аккаунта, не показывая ключ.
2. Открой дашборд: вкладки в шапке — это и есть подключённые аккаунты. Несколько проектов — переключатель слева вверху.
3. Спроси пользователя, какие проекты и аккаунты ему нужны. Нужны не все — пропиши их в `.env.local`:
   - `LIVEDUNE_PROJECT` — названия проектов через запятую, как в выводе `npm run accounts`;
   - `LIVEDUNE_ACCOUNTS` — номера аккаунтов через запятую.

## Если соцсеть показывается неправильно

Сеть определяется по типу аккаунта Livedune в `lib/networks.ts` (поле `match`). Сверены на живых данных: Instagram, Telegram, ВКонтакте, YouTube, TikTok, Дзен. Остальные настроены без проверки и помечены на странице аккаунта.

Если у пользователя такая сеть:

1. Посмотри сырой ответ Livedune: `npm run probe -- page <id аккаунта> posts <с> <по>` (даты `ГГГГ-ММ-ДД`).
2. Поправь в `lib/networks.ts` регулярку `match`, названия реакций `parts` и поставь `verified: true`.
3. Если реакции лежат под другими ключами, добавь их в `toPost` в `lib/report.ts`.
4. Проверь страницу аккаунта и сравни 2–3 поста с кабинетом Livedune.

Предложи пользователю отправить правку пулреквестом в github.com/nosenss/dashcraft — она пригодится остальным.

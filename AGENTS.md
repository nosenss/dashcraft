# Инструкция для ИИ-агента

Пользователь — скорее всего SMM-специалист, не разработчик. Он хочет смотреть статистику своих соцсетей из Livedune в Дашкрафте и ждёт, что ты всё установишь сам. Ключ Livedune он обычно присылает прямо в сообщении.

Как общаться:

- Пиши простым языком, без терминов. Не показывай команды и не проси пользователя ничего запускать в терминале — всё делаешь ты.
- Коротко говори, что делаешь сейчас («скачиваю Дашкрафт», «проверяю ключ»), и предупреждай, что попросишь разрешение на действия.
- Если что-то требует его рук (пароль администратора при установке Node.js, кнопка в Livedune) — объясни, что нажать и где.

## Правила

- **Только локально.** Дашкрафт работает на компьютере пользователя. Не выкладывай его на хостинг, в облако или туннели (ngrok и т. п.) по своей инициативе. Если пользователь сам просит открыть дашборд другим по ссылке, объясни риски: без пароля статистику увидит любой, у кого есть ссылка, и каждый заход тратит лимит API. Выкладывай только с паролем (Vercel Password Protection, Cloudflare Access, basic auth) — см. «Если нужно показать дашборд другим» в README.
- **Ключ Livedune — секрет.** Он хранится только в `.env.local` в корне проекта (файл в `.gitignore`). Не вставляй ключ в код, README, коммиты, логи и адреса страниц, не печатай его в выводе команд и не повторяй в ответах.

## Установка

1. **Ключ.** Если пользователь не прислал ключ — попроси: он на странице https://pro.livedune.com/settings/api (кнопка копирования рядом с ключом). Нет Livedune — дай ссылку на регистрацию: https://pro.livedune.com?from=72df001bad
2. **Node.js 20+.** Проверь `node -v`. Если Node нет или версия старше 20 — поставь: на macOS через `brew install node`, если есть Homebrew; иначе скачай установщик LTS с https://nodejs.org и объясни пользователю, что установщик попросит пароль от компьютера.
3. **Проект.** Скачай Дашкрафт в папку `Dashcraft` в домашней папке пользователя: `git clone https://github.com/nosenss/dashcraft.git ~/Dashcraft`. Нет git — скачай и распакуй https://github.com/nosenss/dashcraft/archive/refs/heads/main.zip. Затем `npm install` в этой папке.
4. **Ключ в настройки.** Запиши в `~/Dashcraft/.env.local` строку `LIVEDUNE_TOKEN=<ключ>` инструментом записи файлов, а не командой в терминале, чтобы ключ не остался в истории команд.
5. **Проверка.** Запусти `npm run setup -- --check`. Команда проверит ключ и напечатает остаток запросов к API, тариф и аккаунты по проектам. Ключ она не выводит.
   - «Livedune не принял ключ» — попроси скопировать ключ заново целиком.
   - Лимит 100 запросов (Триал, Фримиум) — предупреди, что хватит на несколько просмотров, для постоянной работы нужен тариф от «Блогера». Подробнее — раздел «Тариф Livedune» ниже.
6. **Что показывать.** Перескажи проекты и аккаунты из вывода простым списком («В проекте „Кофейня“: Instagram, два Telegram-канала…») и спроси, какие нужны.
   - Все — ничего не делай: в шапке дашборда будет переключатель проектов.
   - Некоторые проекты — `npm run setup -- --projects "Проект А, Проект Б"` (названия как в выводе, регистр не важен).
   - Отдельные аккаунты — `npm run setup -- --accounts "123,456"` (номера из вывода).
7. **Ярлык и запуск.** Выполни `npm run shortcut` — на рабочем столе появится ярлык «Дашкрафт». Открой его, чтобы запустить дашборд так же, как это будет делать пользователь: на macOS `open ~/Desktop/Дашкрафт.command`, на Windows — `Дашкрафт.bat` с рабочего стола. Через 10–20 секунд дашборд откроется в браузере на http://localhost:3737.
8. **Проверь результат.** Вверху не должно быть плашки «Демо», во вкладках — соцсети пользователя. Если плашка есть — ключ не подхватился: проверь `.env.local`.
9. **Скажи пользователю:**
   - дашборд открывается двойным кликом по ярлыку «Дашкрафт» на рабочем столе;
   - откроется ещё служебное окно — его не закрывать, пока смотрит дашборд; закрыл — дашборд выключится до следующего клика по ярлыку;
   - поменять проекты или ключ можно, снова написав тебе.

## Тариф Livedune

Данные идут через API Livedune, а у тарифов разные лимиты запросов в месяц: Триал — 100 на весь период, Фримиум — 100, Блогер — 2 000, Бизнес — 10 000, Агентство — 100 000 ([вики Livedune](https://wiki.livedune.com/ru/articles/11640100-api/)). Дашкрафт тратит примерно 2–4 запроса на аккаунт за каждый новый период, повторные открытия берутся из кэша.

- Если Livedune отвечает 402 или дашборд пишет, что запросы закончились, — дело в лимите, а не в коде: запросы можно докупить в Livedune или дождаться нового месяца.

## Если соцсеть показывается неправильно

Сеть определяется по типу аккаунта Livedune в `lib/networks.ts` (поле `match`). Сверены на живых данных: Instagram, Telegram, ВКонтакте, YouTube, TikTok, Дзен. Остальные настроены без проверки и помечены на странице аккаунта.

Если у пользователя такая сеть:

1. Посмотри сырой ответ Livedune: `npm run probe -- page <id аккаунта> posts <с> <по>` (даты `ГГГГ-ММ-ДД`).
2. Поправь в `lib/networks.ts` регулярку `match`, названия реакций `parts` и поставь `verified: true`.
3. Если реакции лежат под другими ключами, добавь их в `toPost` в `lib/report.ts`.
4. Проверь страницу аккаунта и сравни 2–3 поста с кабинетом Livedune.

Предложи пользователю отправить правку пулреквестом в github.com/nosenss/dashcraft — она пригодится остальным.

## Перед тем как закончить

- Дашборд открыт у пользователя, в нём видны его аккаунты.
- В `git status` нет `.env.local` и папки `.cache/`.
